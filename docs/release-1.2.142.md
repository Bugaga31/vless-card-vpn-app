# VLESS Card 1.2.142

Обычный релиз. Пакет com.vlesscardvpn.beta2, versionCode 253; ставится поверх прошлых версий с той же подписью.

## Авто: волна резервов успевает проверить весь пул
- Бюджет одной волны подготовки резервов теперь подстраивается под размер пула: базовые 45 секунд для шести кандидатов плюс по 8 секунд на каждого лишнего, не больше 90 секунд. Раньше волна всегда обрезалась на 45 секундах, поэтому на большом каталоге и медленной сети хвост пула не успевал провериться даже после снятия лимита в 1.2.141.
- Пул кандидатов вынесен в отдельную функцию, её же использует волна при расчёте бюджета; поведение выбора маршрутов не изменилось: активным остаётся один маршрут, резервы только проверяются.

## Что проверено до публикации
- Автоматика релиза: JVM-тесты модуля (итог в блоке проверок ниже), lint release-сборки, подпись v1+v2+v3 постоянным ключом Beta, установка и запуск универсального APK на эмуляторах Android 11 и 14 (скриншоты приложены к релизу).
- Новые тесты: бюджет волны растёт с размером пула и упирается в потолок 90 секунд; волна использует живой размер пула.
- Матрица масок и сквозная проверка на эмуляторах API 29 и 33 запускаются на этом же коммите; набор из восьми серверов и волна резервов проверяются в E2E как раньше.

Работа с реальными мостами Tor, на настоящем телефоне и в сетях операторов этой версией не проверялась.
