# VLESS Card 1.2.139

Tor-режим стал полнее, импорт конфигов — шире, а Авто теперь учитывает не
только сырую скорость из облака, но и то, насколько стабильно сервер
работает у телефонов на вашем операторе.

## Tor
- **Страна выхода Tor**: в настройках Tor-режима выбирается страна выхода
  (Авто/Россия/NL/DE/FI/SE/TR). В torrc попадают `ExitNodes {cc}` и
  `StrictNodes 1` при выбранной стране.
- **Подписки через Tor**: когда включён torRouting, подписки качаются
  через локальный Tor (SOCKS 127.0.0.1:9050) первым транспортом, иначе
  как последний шанс. Таймауты под Tor увеличены (connect 25 с, read 40 с).

## Импорт
- **Новые схемы tuic:// и anytls://** разбираются как обычные ссылки;
  ссылка из другого клиента открывается в приложении.
- **«Добавить» → «Из файла»**: импорт .conf/.json/.txt из любого
  приложения через системный выбор файла.

## Авто: надёжность, а не только скорость
- Кандидаты из облака ранжируются с учётом процента успешных проверок
  на вашем операторе (бета-сглаживание): чуть более медленный, но
  стабильный сервер обгоняет чуть более быстрый «флапающий».
- Операторский замер скорости заменяет замер с GitHub только когда у
  него минимум три проверки: двух удачных мало, чтобы описать оператора.
- Порядок и отсечка без данных по оператору не изменились.

## Стабильность
- Менее навязчивая оптимизация маршрута: первый проход через 60 с,
  далее период 120–300 с вместо 30 с — маршрут не дёргается.
- Уведомление спокойнее: живая скорость выключена по умолчанию
  (включается галкой «Скорость в уведомлении»), обновление раз в 30 с.

## Как и раньше
- Установка поверх прошлых версий с той же подписью; ARM64 APK — то же
  приложение для большинства современных телефонов, примерно вдвое меньше.
- Успешная проверка в одной сети не гарантирует работу на любом
  устройстве, операторе или сервере.
