# VLESS Card 1.2.149

Обычный релиз. Пакет com.vlesscardvpn.beta2, versionCode 260; ставится поверх прошлых версий с той же подписью.

## Все конфиги в работе

- Поиск больше не пробует выборочно две-три транспортные семьи: теперь каждая семья конфигов, которая есть в списке (TCP, WebSocket, gRPC, HTTP/2, QUIC, XTLS и варианты TLS/Reality), получает своего представителя в первой волне поиска. Раньше в волну попадало до трёх представителей разных конфигов, остальные молча ждали следующих волн.
- Волна заполняется по одному маршруту на семью: лидер рейтинга плюс по представителю от каждой остальной семьи, до размера волны. Дубликаты внутри одной семьи не расходуют слоты, а разные конфиги не вытесняются рейтингом.
