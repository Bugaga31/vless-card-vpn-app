# VLESS Card 1.2.148

Обычный релиз. Пакет com.vlesscardvpn.beta2, versionCode 259; ставится поверх прошлых версий с той же подписью.

## Подбор сервера быстрее

- Первая волна поиска больше не пропускает дешёвую TCP-проверку. Раньше первые ~20 кандидатов сразу уходили в полный HTTPS-тест с бюджетом 4-5 с на сервер: мёртвый хост горел весь бюджет в своём слоте, и волна с большим числом мёртвых маршрутов тянулась 10-20 с. Теперь перед полным тестом идёт та же TCP-проверка, что и в резервных волнах: 0,6 с на сервер, до 32 параллельно, то есть вся первая волна укладывается примерно в секунду. Полный HTTPS-тест получают только хосты, отвечающие по TCP.
- Если TCP не ответил ни у одного кандидата (сеть режет прямые соединения), приложение возвращается к обычному полному тесту всего списка: ничего не теряется.
