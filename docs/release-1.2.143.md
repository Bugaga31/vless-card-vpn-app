# VLESS Card 1.2.143

Обычный релиз. Пакет com.vlesscardvpn.beta2, versionCode 254.

## Авто-блокировщик рекламы

- Новый `AdBlockPolicy`: к встроенному geosite добавляется живой список рекламных доменов, который приложение обновляет само в фоне каждые 3 дня (AdGuard DNS filter + независимое зеркало на jsDelivr), без обновления приложения.
- Встроенный сид-список крупных рекламных сетей (DoubleClick, Criteo, Taboola, pubMatic, AppLovin, AdFox, Yandex Ads и др.) работает с самого первого подключения, до первой загрузки списка.
- Список переживает перезапуск: сохраняется в файлы приложения и восстанавливается при следующем подключении. Если загрузка не удалась или список подозрительно маленький, остаётся прежний.
- Резолверы (DoH-имена, которые использует сам туннель) никогда не блокируются, даже если попали в список.
- Обновление не мешает подключению: идёт в фоне и подхватывается при следующей сборке конфига.
- Отключается старым переключателем «Блокировать рекламу и трекеры»; «всегда напрямую» по-прежнему побеждает блокировку.

## Резервы (из 1.2.142)

- Бюджет волны резервов растёт с размером пула: 45с база, +8с за каждого кандидата сверх 6, потолок 90с (коммит 5f39613f).

## Тесты

- Новый `AdBlockAutoR253Test`: разбор форматов AdGuard/hosts, дедупликация и потолок, исключение резолверов, «тонкая» загрузка отбрасывается, живой список попадает в правило блокировки конфига, файл восстанавливается при загрузке.
