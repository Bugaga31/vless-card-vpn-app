# VLESS Card 1.2.147

Обычный релиз. Пакет com.vlesscardvpn.beta2, versionCode 258; ставится поверх прошлых версий с той же подписью.

## Подключение и переподключение быстрее

- Первая проверка после подключения или переподключения стала короче: если сервер прошёл полную проверку меньше 2 минут назад, приложение пингует его с коротким бюджетом (3,5 с вместо 6,5 с) и быстрее делает вторую попытку (1,5 с вместо 3 с). Неизвестный или протухший маршрут проверяется по-прежнему внимательно.
- Это же ускоряет переподключение после смены сети: маршрут, который только что подтвердился через живой пробой, подтверждается повторно без долгого ожидания.
- Большие волны фонового поиска больше не могут висеть вечно: бюджет волны для пула больше шести серверов — плюс 5 с за сервер вместо 8, жёсткий потолок волны 60 с вместо 90. Обычные проходы не меняются.
