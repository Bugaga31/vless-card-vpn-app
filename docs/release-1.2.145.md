# VLESS Card 1.2.145

Обычный релиз. Пакет com.vlesscardvpn.beta2, versionCode 256; ставится поверх прошлых версий с той же подписью.

## Живой график скорости за сессию

- На главном экране появился график скорости: загрузка и отдача, последние минуты, обновление раз в 5 секунд.
- Скорость считает сервис, пока VPN подключён: при открытии экрана график уже заполнен, даже если приложение долго было закрыто.
- Строка «Сейчас» теперь берёт ту же измеренную скорость, поэтому показания согласованны.
- Сброс системных счётчиков (например, после перезагрузки телефона) не даёт ложного всплеска: такой замер считается нулевым.
